Getting started
Up and running in minutes

One pnpm command installs everything. Four steps to a running app.

1

Clone the repository

Pull the monorepo and enter the project root.

git clone https://github.com/your-username/ticket-bro.git
cd ticket-bro
2

Install dependencies

pnpm workspaces installs root, backend, and frontend in a single command.

pnpm install
3

Configure environment

Copy and fill in both env files. You need MongoDB, Redis, Cloudinary, and SMTP credentials.

cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# Key backend variables
MONGODB_URI=mongodb://localhost:27017/ticketbro
JWT_ACCESS_SECRET=your_64byte_random_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
EMAIL_USER=your@email.com

# Frontend
VITE_API_URL=http://localhost:5000/api/v1
VITE_SOCKET_URL=http://localhost:5000
4

Run the application

Turborepo starts both concurrently.

pnpm dev
# Frontend
localhost:5173
# Backend API
localhost:5000/api/v1

Security
Defense in depth across every layer

Role hierarchy: Super Admin → Admin → Moderator → Organizer → User, enforced at both route and service levels.

🔑 Passwords

bcrypt with 12 salt rounds. Never stored in plain text or logged anywhere.

🎟 JWT tokens

15-minute access tokens + 7-day refresh tokens with rotation on every use.

📱 Two-factor auth

RFC 6238 TOTP via speakeasy. Works with Google Authenticator and Authy.

🛡 HTTP headers

Helmet.js enforces XSS, CSRF, and clickjacking protections on every response.

🚦 Rate limiting

express-rate-limit backed by Redis to block brute-force and abuse patterns.

💉 NoSQL injection

express-mongo-sanitize strips malicious operators from all incoming query data.

🎫 Ticket fraud

Each QR code is unique and single-use, validated server-side on check-in.

📋 Audit logging

Every admin action logged with actor ID, target, action type, and timestamp.

Carbon footprint
Built with environmental accountability

Real-time CO₂ tracking using the Sustainable Web Design model — surfaced to every visitor via a live widget.

The useCarbonFootprint hook uses the browser's PerformanceObserver API to track all network transfers live. The backend middleware measures bytes per request via @tgwf/co2.

CO₂ (g) = Bytes Transferred × 0.0000001822
~1.25g CO₂eq — current <1g CO₂eq — target (Excellent)

Reaching Excellent requires lazy-loading all routes, Vite manual chunk splitting, and Brotli compression — projected to push the score to 0.4–0.6g CO₂eq.
